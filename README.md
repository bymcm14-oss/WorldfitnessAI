# 🏋️ WorldfitnessAI

**WorldfitnessAI** es una aplicación web desarrollada para el gimnasio **Worldfitness (Benahadux, Almería)**.

Su objetivo es generar **rutinas de entrenamiento totalmente personalizadas** mediante Inteligencia Artificial, adaptándose a las necesidades de cada usuario utilizando únicamente el material disponible en el gimnasio.

---

## ✨ Características

* 🤖 Generación automática de rutinas mediante IA.
* 💪 Adaptación al objetivo del usuario.
* 📈 Adaptación al nivel de experiencia.
* 📅 Rutinas de 2 a 6 días por semana.
* ⏱️ Adaptación al tiempo disponible por sesión.
* 🏋️ Uso exclusivo del equipamiento real de Worldfitness.
* 🚫 Evita ejercicios inexistentes o material no disponible.
* 📋 Rutinas organizadas por grupos musculares.
* 💡 Consejos personalizados al finalizar cada entrenamiento.
* 📱 Interfaz sencilla y optimizada para dispositivos móviles mediante código QR.
